Start a hypothesis

The agent reads the entities the goal is about out of its text, writes the DAG and runs it; the goal is met only when each criterion's assertion holds. A missing node blocks the run until someone adds it. Give the entities in the goal — any kind the framework knows, not just DNA: a sequence, a structure, a set of contacts. Nothing is fetched for you, so a goal that names something without giving its value gets no input for it. Drop a FASTA file on the goal to attach it: it is saved and mentioned as FASTAFile <id>, which the run resolves to the file itself.
Hypothesis optional
Success criteria none
What must hold of the outcome for the goal to count as met. Left empty, the verifier judges the goal alone.
Observations none
What is already known that bears on the goal. Drop the records that do not belong and correct the summaries: the builder is shown this list as it chooses its nodes and thresholds, and a summary is the agent's reading of the record, not a verified claim. Left empty, the builder searches for itself.
Limits default
Most plans the loop will try before it stops. Left empty, it uses its own default, 20. The token ceiling, 500,000, usually stops a run first.
